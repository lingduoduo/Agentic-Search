Retrieval Server — All 7 Modes

  • • demo.py (TF-IDF, no Java) · retrieval.py (BM25 or E5/BGE FAISS) · retrieval_rerank.py (+ cross-encoder)
  • • hybrid_rerank.py: Dense + BM25 RRF + rerank — recommended for AgenticRAGLoop; --hybrid_alpha 0.5
  • • google.py (Google CSE) · serp.py (SerpAPI) · browser.py (playwright-cli ~5–10s, no API key)
  • • QueryEnhancer: decompose() (2–4 sub-queries) + hyde(); degrades gracefully without LLM
  • • index_builder.py: FAISS Flat + BM25 from corpus.jsonl; indexing_pipeline.py async background
  • • BM25 requires Java (Pyserini/Lucene); FAISS via conda on Apple Silicon; --device cpu|cuda

RL Training — Reward + GRPO + PPO

  • • SearchRewardFunction: format(0.2) + search_use(0.3) + answer_length(0.1) + exact_match(0.4)
  • • GRPO: score_prompt_group → compute_grpo_outcome_advantage; G rollouts per prompt group-relative advantages
  • • PPO: compute_ppo_policy_loss_core + compute_value_loss + AdaptiveKLController; clip_eps=0.2
  • • src/model/generation.py: policy loss + tensor helpers; IntentPipeline classifier; REINFORCE helpers
  • • data.py: prepare_search_qa (FlashRAG NQ/TriviaQA parquet) + prepare_search_rag (cached retrieval --topk 3)
  • • XML protocol: <think><search><information><answer>; mask <information> from policy/SFT loss; run without GPU
